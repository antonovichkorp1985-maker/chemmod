# ChemMod v1.0.2-test.5 — CM-2 gas system without redstone (pressure safety, inhalation, respirator)

Minecraft 1.21.1 · NeoForge 21.1.251 · Java 21. Create remains optional. This is an immutable **GitHub prerelease** for owner testing, not a production release, CurseForge publication, or a claim that M0–M4 have been accepted.

## New in this candidate — CM-2: M4 gas system without redstone

- **ClosedVessel** now carries `wallStrengthPascals` in its constructor and rejects negative or zero strength; wall burst check `bursts()` compares pressure against the vessel's own strength
- **Pressure relief valve** `releaseAtPressure(maxPressurePascals)`: releases gas proportionally from all species when internal pressure exceeds a threshold; returns moles released or 0
- **Manual vent** `ventMoles(requestedMoles)` and `empty()`: remove gas proportionally or entirely; returns moles actually removed
- **GasTankBlockEntity** uses `WALL_STRENGTH_PASCALS` when constructing `ClosedVessel`, so the tank's own wall strength governs its burst behavior
- **RespiratorFilter** (finite sorbent capacity): `capacityMicromoles` limits total adsorption; `adsorb()` returns null when capacity would be exceeded; `remainingCapacity()` reports headroom
- No redstone: ventilation, valves, and mechanisms work via pressure/temperature differentials and manual controls only

## Existing functionality in this candidate

- All CM-1 core: Phase enum, metathesis driving forces, solubility table, 16 unit tests
- Graph-based sparse gas field, gas-cell identity persistence, six-direction diffusion, visible composition tint, balanced hydrogen combustion
- Existing M0–M3 source work: vial/flask transfer, chemical reactor, Cu(110) coupon profile
- Iteration 3 block/item models with compact single-line JSON arrays, restored overrides in substance_vial.json, 32×32 textures

## Limits — do not count as accepted

- CI and GameTests are automated evidence, not owner real-pack acceptance. M0–M4 real-pack checks remain open.
- The gas system models pressure and toxicity by mechanism; it does not model mucosal damage concentration curves, HCl hydrocyanic gas contact, calibrated background-air inventory, or room-concentration simulation.
- Respirator sorbent capacity is in micromoles; no player exposure time or breakthrough curve is implemented.
- General graph rules have an unbounded theoretical input space; the creative sample set is finite.

2. Download `chemmod-1.0.2-test.5.jar` and its `.sha256` from this release; verify with `sha256sum -c chemmod-1.0.2-test.5.jar.sha256`.
3. Install the exact same JAR on server and clients with Minecraft 1.21.1, NeoForge 21.1.251 and Java 21.
4. Follow [`docs/testing/v1.0.2-test.5.md`](../testing/v1.0.2-test.5.md). Use a disposable copied world for gas injection. Record the JAR checksum, full mod list, logs and pass/fail notes.
