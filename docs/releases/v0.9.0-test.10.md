# ChemMod v0.9.0-test.10 — газ: закрытый объём, горение и взрыв в мире

Minecraft **1.21.1** · NeoForge **21.1.251** · Java **21**.
Create **6.0.10** остаётся необязательным. Новых обязательных модов нет.

Эта версия завершает этап B плана ADR-0004: газовая фаза выходит из ядра в мир.
Появляется блок **газового бака** (`chemmod:gas_tank`) — жёсткий герметичный
объём, который считает давление, горит и взрывается по реальной физике, а не по
условным числам.

## Игровые изменения

- **Газовый бак (`chemmod:gas_tank`).** Жёсткий герметичный объём 0,05 м³.
  Давление считается по закону идеального газа с законом Дальтона по парциальным
  давлениям: `P = (Σn)·R·T/V`.
- **Взрыв по прочности материала.** Когда давление превышает предел стенки
  (500 кПа), бак пробивается: выпадает предметом и, если внутри горючее
  (H₂/CH₄/CO), рвётся с взрывом. Это случай Гинденбурга — оболочка не выдерживает
  внутреннего давления.
- **Горение (окисление).** Огонь или лава по соседству поджигают смесь. Сгорание
  идёт только внутри пределов воспламеняемости (для H₂ в воздухе ≈16–100 об.%),
  стехиометрически, с выделением тепла: `2 H₂ + O₂ → 2 H₂O`, +241,8 кДж/моль H₂.
  Газ раскаляется, давление скачком растёт — вплоть до разрушения бака.
- **Слишком бедная смесь не горит.** Вне пределов воспламеняемости `ignite()`
  ничего не делает: водород при 9 об.% в кислороде не вспыхивает.
- **Показания.** ПКМ по баку показывает давление (кПа) и температуру (K).
- Бак ставится как обычный блок, ломается и выпадает, содержимое сохраняется.

## Граница ответственности

Ракетная **тяга** остаётся за модом Аэронавтики. ChemMod поставляет горение,
сброс газа и окисление; сопло и тягу считает Аэронавтика.

## Как проверить

Поставьте газовый бак. Закачайте побольше газа — при превышении 500 кПа бак
взорвётся. Закачайте водород с кислородом (стехиометрически) и подожгите
факелом/лавой — вспышка, сильный нагрев, скачок давления. Закачайте слишком
бедную смесь (мало водорода) — она не загорится.

[Чек-лист](https://github.com/antonovichkorp1985-maker/chemmod/blob/v0.9.0-test.10/docs/testing/v0.9.0-test.10.md).

## Установка

Резервная копия мира обязательна. Замените прежний ChemMod JAR; сервер и клиенты
должны использовать одинаковый test.10. Формат колб, реактора и держателей не
изменён; добавлен новый блок (газовый бак). Опубликованные test.9 и более ранние
не переиздаются.

```sh
sha256sum -c chemmod-0.9.0-test.10.jar.sha256
```
