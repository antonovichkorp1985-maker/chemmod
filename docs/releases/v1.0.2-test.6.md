# ChemMod v1.0.2-test.6 — CM-2 extended: block mass API, ambient gas API, E0 catenary cables

Minecraft 1.21.1 · NeoForge 21.1.251 · Java 21. Create remains optional. This is an immutable **GitHub prerelease** for owner testing, not a production release, CurseForge publication, or a claim that M0–M4 have been accepted.

## New in this candidate — CM-2 extended: mass, atmosphere, cables

- **Block mass API** for Aeronautics Plus Centre of Mass
  - `MaterialDensityRegistry` with real-world densities (copper 8960, steel 7850, aluminium 2700 kg/m³, ...)
  - `BlockMassApi.solidBlockMassKilograms()` / `hollowBlockMassKilograms()` / `gasTankTotalMassKilograms()`
  - Shell mass from volume × density × packingFactor; gas mass from ClosedVessel moles × molar mass
  - Gas tank gets heavier as gas is pumped in — verifiable in unit tests
- **WorldGasField AmbientGasApi**
  - Barometric pressure Pa, temperature K, density kg/m³ at geometric altitude (not Minecraft Y)
  - Vacuum threshold below which medium reads as empty
  - Aeronautics Plus reads real medium, not a hardcoded table
- **E0: Physical cables without redstone**
  - Catenary mathematics: Newton-Raphson solve for parameter a from span/length/weight-per-metre
  - `CableSegment` in exactly 3 states: BARE / INSULATED / BREACHED
  - Joule heating I²R, temperature rise, insulation breakdown temperature, overvoltage breakdown
  - Short circuit when bare/breached segment is wet or grounded
  - Blocks: `cable_terminal_bare`, `cable_terminal_insulated`
- No redstone: ventilation, valves, and mechanisms work via pressure/temperature differentials only

## Limits — do not count as accepted

- CI and GameTests are automated evidence, not owner real-pack acceptance. M0–M4 real-pack checks remain open.
- Catenary model assumes uniform cable, level supports, static load; no wind, ice, or dynamic sag.
- Block mass API depends on density registration; unregistered materials return null (NO_MODEL), never invented values.
- AmbientGasApi uses Earth ISA; other planets require constructor parameters, not a fork.
