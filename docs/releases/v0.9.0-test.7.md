# ChemMod v0.9.0-test.7 — стойка, поднос и лабораторные модели

Minecraft **1.21.1** · NeoForge **21.1.251** · Java **21**.
Create **6.0.10** остаётся необязательным. Новых обязательных модов нет.

## Игровые изменения

- Стойка для пробирок на **6 сосудов** и лабораторный поднос на **4 сосуда**.
  Есть рецепты выживания, названия и подсказки RU/EN.
- Стойка и поднос устанавливаются в одной клетке. ПКМ с сосудом по позиции
  переносит один предмет; ПКМ пустой рукой забирает его. Сохраняются компоненты
  содержимого; химические реакции в держателях не запускаются.
- Сохранение отдельных позиций и ID установленных держателей, синхронизация
  для отображения сосудов, выпадение содержимого при разрушении/потере опоры.
- Собственные объёмные модели и текстуры: стойка, поднос, сосуды и прототип
  реактора. Различимые этикетки пустого сосуда, вещества и смеси — это маркировка
  типа содержимого, не предсказанный цвет жидкости.
- GUI реактора шире: полное **«Катализатор»** вместо «Кат.», понятные группы
  слотов и пояснения при наведении на их заголовки.

## Как попробовать

Найдите «Стойка для пробирок» и «Лабораторный поднос» во вкладке ChemMod либо
скрафтите их. Поставьте первый держатель на цельный блок. Вторым предметом
нажмите ПКМ по первому держателю: обе части займут одну клетку.
Поставьте сосуды на выбранные позиции и заберите их пустой рукой.

[Подробная инструкция, рецепты и чек-лист](https://github.com/antonovichkorp1985-maker/chemmod/blob/v0.9.0-test.7/docs/testing/v0.9.0-test.7.md).

## Границы версии

Это первый игровой адаптер: две фиксированные части без свободного вращения;
разрушение клетки снимает обе части. Перенос заполненного подноса одним
предметом, нагреватели, насос, шланги и мерная посуда ещё не реализованы.
Поддержка произвольных поверхностей Chisels & Bits и мебели не заявляется:
пока требуется полная верхняя опора на высоте блока.

Автотесты проверяют содержимое, размещение, отказы, NBT, взаимодействие и ресурсы.
Настоящий клиентский рендер, удобство GUI, restart и multiplayer требуют ручной
проверки. Полная приёмка M3 остаётся открытой.

## Установка

Резервная копия мира обязательна. Замените прежний ChemMod JAR; сервер и клиенты
должны использовать одинаковый test.7. Формат прежних колб/реактора не изменён.
Новые держатели не поддерживаются старым модом — откат через резервную копию.
Test.6 и более ранние опубликованные версии не переиздаются.

```sh
sha256sum -c chemmod-0.9.0-test.7.jar.sha256
```
