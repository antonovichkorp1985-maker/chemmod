# Release v1.0.2-test.8

## Overview
Wave 5 release adding transformer physics fix, Stage E2 grid equipment, volumetric gas cloud physics, and blast shockwave model with Rankine-Hugoniot relations.

## Changes

### Fixed
- **ElectricalNetwork**: Replaced placeholder transformer branch impedance across ideal transformers with physically coupled primary/secondary admittance stamping (turns ratio n = N1/N2, winding series resistance, magnetizing conductance)
- Added unit tests proving V2/V1 = N2/N1 and power conservation
- **BlastShockwaveModel**: Added Rankine-Hugoniot normal reflection coefficient for shock wave in air (gamma = 1.4)
  - Cr = (14*P0 + 8*ΔP) / (7*P0 + ΔP)
  - As ΔP -> 0 (acoustic limit): Cr -> 2.0
  - As ΔP -> ∞ (strong shock): Cr -> 8.0
  - Monotonically increasing from 2.0 to 8.0
- **WorldGasField**: Added proper volumetric cloud ignition with stoichiometric O2 consumption and combustion product formation (CO2, H2O)

### Added
- **ElectricalNetwork**: Ideal transformer with turns ratio, primary/secondary winding resistance, core loss conductance integrated into G*V=I solver via admittance stamping
- **ElectricalNetworkTest**: 7 new unit tests for transformer physics (voltage step-up/down, power conservation, impedance reflection, center-tap voltage splitting, load reflection)
- **GridEquipment** (Stage E2):
  - `SwitchBranch` with CLOSED/OPEN/WELDED states and voltage/current ratings
  - `MultiTapTransformerBranch` with expandable taps for multi-winding transformers
  - `ArcFlashModel` with arc voltage/power/incident energy and temperature estimation
  - `WireInsulationModel` with HV/MV/LV insulation classes and breakdown evaluation
  - `GroundFaultModel`: soil resistivity models and ground rod resistance (Dwight's formula)
  - `SurgeProtection`: SparkGap and MetalOxideVaristor transient overvoltage protection
- **VolumetricGasCloud**: Spherical cloud with density, buoyancy, terminal velocity, concentration-at-point
- **BlastShockwaveModel**: Rankine-Hugoniot overpressure peak, arrival time, impulse, dynamic pressure, Wilson cloud check
- **VolumetricGasCloudManager**: World-scale cloud advancement and density querying
- **WorldGasField**: `igniteVolumetricCloud()` method for spark-initiated cloud detonation with stoichiometric O2 consumption
- **AmbientGasApi**: Dynamic `peakBlastPressurePascalsAt()`, `peakBlastWindMetersPerSecondAt()`, `totalGasDensityAt()` methods using active blast sources and cloud manager

### Changed
- `build.gradle.kts`: version `1.0.2-test.7` → `1.0.2-test.8`

## Testing
- All core unit tests pass (15 ElectricalNetwork tests including 7 new transformer tests)
- BlastShockwaveModel unit tests for normal reflection coefficient limits (acoustic -> 2.0, strong shock -> 8.0)
- WorldGasField volumetric cloud ignition stoichiometry verified

- Zero redstone dependencies maintained
- Pure electrodynamics and gas physics in SI units
- No substance lookup tables; properties computed from elements/bonds
- Backward compatible with existing ElectricalNetwork API
