# ChemMod v1.0.2-test.1 — immutable M0–M4 player-test candidate

Minecraft 1.21.1 · NeoForge 21.1.251 · Java 21. Create remains optional. This is an immutable **GitHub prerelease** explicitly requested by the owner for testing. It is not a production release, CurseForge publication, or a claim that M0–M4 have been accepted.

## What this candidate adds for testing

- Graph-identified gases in the per-level sparse world field, saved through the level attachment codec.
- Six-direction symmetric diffusion, buoyant settling, sky-visible dilution, and composition-derived particle tint where the model has a tint result.
- Integration of cell updates with existing data-defined environmental reaction rules. In a cell containing a supported ignition source, the bundled balanced hydrogen rule can turn H2 and O2 into graph-identified H2O.
- Operator-only commands `/chem gas release` and `/chem gas inspect`, limited to substances in the finite bundled reference-name directory, so the owner can exercise and inspect the world field without modifying the deferred Stage-B gas tank.
- The release also contains the existing M0–M3 work on the branch. Use the supplied acceptance checklist for the exact M2/M3 scenarios and limitations.

## Not implemented — do not mark as passed

- M4 C1 full acceptance: no player damage/debuff from chlorine exposure, no gas mask/filter, no powered room-ventilation block, and no implemented tank leak. Core `GasToxicity` is not wired to living entities. Open-sky dilution is not a fan/vent simulation.
- M4 C2 explosion: no validated hydrogen LEL/UEL envelope, no pressure-wave/damage model, and no bounded block-destruction budget. Current world ignition is a 500 K rule gate, not a gas-temperature measurement. The test command exercises balanced chemistry only; it does not imply a bomb or explosion simulation.
- The current gas field stores explicit molecular contents but not the background-air inventory. Do not treat the command quantities as a calibrated room concentration or use them as a safety tool.
- M0–M3 owner acceptance and the 100-machine Spark performance gate remain open. The `copper_catalyst_coupon` is a prepared Cu(110) reference surface limited to ethanol dehydrogenation; ordinary copper ingots and the acetic-acid pathway abstractions are not experimentally validated by that surface.

## Install

1. Back up the world and stop the client/server.
2. Download `chemmod-1.0.2-test.1.jar` and its `.sha256` file from this release; verify the hash with `sha256sum -c chemmod-1.0.2-test.1.jar.sha256`.
3. Install that exact JAR on the dedicated server and every client. Start with Minecraft 1.21.1, NeoForge 21.1.251 and Java 21.
4. Follow [`docs/testing/v1.0.2-test.1.md`](../testing/v1.0.2-test.1.md). Record logs, screenshots, exact steps, versions and the JAR checksum. Use a disposable copied world for gas injection.
