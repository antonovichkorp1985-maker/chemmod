# ChemMod v1.0.2-test.7 — E1 Kirchhoff circuit solver, electrochemical EMF, fuses, spark ignition

Minecraft 1.21.1 · NeoForge 21.1.251 · Java 21. Create remains optional. This is an immutable **GitHub prerelease** for owner testing, not a production release, CurseForge publication, or a claim that M0–M4 have been accepted.

## New in this candidate — E1: real Kirchhoff circuit solver without redstone

- **ElectricalNetwork** (`G * V = I`): nodal-analysis DC solver via Gaussian elimination with partial pivoting on pure Kotlin
  - `ElectricalNode` including ground node (V = 0.0 V); multiple isolated subgraphs and floating nodes return finite values, never NaN/Infinity
  - `ResistorBranch` (cable segment / load), `VoltageSourceBranch` (EMF + internal resistance > 0)
- **CableSegment** extended from E0: conductor melting temperatures (Cu 1357.77 K, Al 933.47 K, Pb 600.61 K, Fe 1811.0 K, Au 1337.33 K, Pt 2041.4 K, Ag 1234.93 K); `OPEN_MELTED` fuse state; `groundFaultConductance()` for water/earth leakage
- **GalvanicCellModel**: EMF from standard electrode potentials (Daniel cell Cu/Zn ~1.10 V, lead-acid PbO2/Pb ~1.59 V); Faraday's law dn/dt = I/(z·F), F = 96485.33212 C/mol; unknown electrode pair = NO_MODEL (null)
- **SparkIgnitionEvaluator**: spark energy vs minimum ignition energy; fuel + O2 within real flammability limits (LEL..UEL); short-circuit/overvoltage spark events can ignite WorldGasField mixtures
- **E1 NeoForge blocks** (no redstone): `galvanic_battery`, `dynamo_generator`, `electric_heater`

## Limits — do not count as accepted

- CI and GameTests are automated evidence, not owner real-pack acceptance. M0–M4 real-pack checks remain open.
- Circuit solver assumes lumped-element DC/quasi-static; no AC, no skin effect, no transmission lines.
- Melting temperatures are for pure elements; alloys and practical conductors may differ. Unknown melting point = null (NO_MODEL), never invented.
- Spark ignition uses indicative MIE values; real MIE depends on pressure, temperature, electrode geometry, and fuel/oxidizer ratio.
- No redstone anywhere: ventilation, valves, and mechanisms work via pressure/temperature differentials and manual/electrical control only.
