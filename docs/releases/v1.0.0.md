# ChemMod 1.0.0 — первый полноценный релиз

Первый релиз без пометки «пререлиз». Мод сознательно остаётся неполным: это не заявка
на завершённость, а фиксация состояния, которое собирается, проходит CI и имеет смысл
ставить в сборку.

## Что входит

**Идентичность веществ**
- вещество — это граф, а не строка; молекулярная формула выводится из графа;
- изоморфизм по алгоритму Вейсфелера–Лемана: одинаковые графы — одно вещество,
  где бы оно ни появилось;
- 28 тривиальных имён и 37 записей словаря; 118 элементов.

**Свойства, выводимые из свойств атомов**
- температура кипения из поляризуемости и водородных связей;
- ионность связи из разности электроотрицательностей (Полинг): `1 − exp(−¼·Δχ²)`;
- тип кристаллической решётки из отношения ионных радиусов;
- растворимость по классам ионов;
- плавучесть в воздухе из молярной массы;
- пределы воспламеняемости из стехиометрии (правило Джонса).

В данных: электроотрицательность у 62 из 118 элементов, ионный радиус у 55,
характерные заряды ионов у 56. Там, где значения нет, модель отвечает «нет модели»,
а не подставляет ноль.

**Реакции**
- 16 общих правил вместо перечня веществ: горение, пиролиз, гидратация, обмен,
  дегидратация, аммонолиз, окисление, кислотно-основные, этерификация;
- выход и энергия по правилу Ле Шателье; обратимость; равновесие;
- каталитическое ускорение и ингибирование с отравлением катализатора.

**Газовое поле**
- разреженное поле: считаются только занятые клетки;
- диффузия по градиенту концентрации, плавучесть по молярной массе, барометрическая
  формула в столбе;
- планетарная атмосфера по ISA с параметрами планеты как данными;
- цвет газа как производная от состава (смешение по закону Бугера — Ламберта — Бера),
  рендер частицами;
- токсичность по механизму, без выдуманных доз.

## Что НЕ входит

Честный список, потому что «релиз» не должен его скрывать:

- **мировой адаптер газа не проверен в реальной сборке.** Он зелёный в CI и в
  gametest-обвязке, но ADR-0004 требует прогона владельцем на настоящей сборке, и
  этого прогона ещё не было;
- реактивность газа с окружением не реализована;
- нет материалов сосудов (стекло, PTFE), сортов стекла, прозрачности пробирок,
  цветов твёрдых веществ как данных;
- кинетика в мире — скорость горения, а не кинетика Аррениуса;
- иконки — плейсхолдеры;
- энергия активации и каталитическая активность не выводятся в принципе: это
  офлайн-расчёт квантовой химией и поставка чисел как данных.

## Граница с Aeronautics Plus

`ChemAtmosphere` отдаёт ρ, P и T фона по геометрической высоте. Это статические
методы на примитивах, доступные через `ModList` и рефлексию без импорта ChemMod.
**Тяга остаётся зоной ответственности Aeronautics Plus** — ChemMod её не считает.
API содержимого бака не публикуется, пока в мире нельзя заправить бак: ADR-0004
запрещает публиковать обещание без реализации.
