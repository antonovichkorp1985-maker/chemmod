# ChemMod v1.0.2-test.3 — immutable M0–M4 player-test candidate

Minecraft 1.21.1 · NeoForge 21.1.251 · Java 21. Create remains optional. This is an immutable **GitHub prerelease** for owner testing, not a production release, CurseForge publication, or a claim that M0–M4 have been accepted.

## New in this candidate

- Iteration 3 block/item models: `chemmod:gas_tank`, `chemmod:kinetic_gas_exhaust` and `chemmod:kinetic_ore_separator` now use dedicated `chemmod:block/lab/*` textures (steel, dark, panel) with compact single-line JSON arrays; item models carry `gui`/`ground` display transforms.
- Restored the `overrides` block in `models/item/substance_vial.json` for `chemmod:contents` 1 (pure) and 2 (mixture), keeping the new compact `display` block.
- Scaled `textures/block/lab/wood.png`, `glass.png` and `panel.png` nearest-neighbor from 16×16 to the contract-required 32×32 PNG.

## Existing functionality in this candidate

- The branch's graph-based sparse gas field, gas-cell identity persistence, six-direction diffusion, visible composition tint, and balanced hydrogen combustion test path.
- Existing M0–M3 source work, including vial/flask transfer, the chemical reactor, and the prepared Cu(110) coupon profile for ethanol dehydrogenation.

## Limits — do not count as accepted

- CI and GameTests are automated evidence, not owner real-pack acceptance. M0–M3 real-pack checks, the M3 chemistry/catalyst review, and the required 100-machine Spark profile remain open.
- The book reports model outputs only. It does not assess toxicity or safe handling, and it reports no value where a model has no result.
- General graph rules have an unbounded theoretical input space; the creative sample set is finite and does not claim to enumerate every possible reaction product.
- M4 still lacks player exposure effects, masks/filters, a powered room ventilator, a tank leak, validated H2/air LEL/UEL, blast/damage, and bounded block destruction. The world ignition gate is not a temperature measurement or a safety demonstration.
- The gas field does not store a calibrated background-air inventory. `/chem gas release` injects finite named reference examples for testing; it is not a leak or room-concentration simulator.
- The existing `copper_catalyst_coupon` is a prepared Cu(110) reference surface used only for ethanol dehydrogenation. It does not validate the separate acetic-acid pathways or ordinary copper ingots.

## Install and test

1. Back up the world and stop the client/server.
2. Download `chemmod-1.0.2-test.3.jar` and its `.sha256` from this release; verify with `sha256sum -c chemmod-1.0.2-test.3.jar.sha256`.
3. Install the exact same JAR on server and clients with Minecraft 1.21.1, NeoForge 21.1.251 and Java 21.
4. Follow [`docs/testing/v1.0.2-test.3.md`](../testing/v1.0.2-test.3.md). Use a disposable copied world for gas injection. Record the JAR checksum, full mod list, logs and pass/fail notes.

The publisher records the exact tested source commit and SHA-256. Tags and releases are never overwritten.
