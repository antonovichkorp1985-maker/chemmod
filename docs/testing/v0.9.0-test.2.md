# Ручная проверка ChemMod v0.9.0-test.2

Этот чек-лист относится к GitHub prerelease
[`v0.9.0-test.2`](https://github.com/antonovichkorp1985-maker/chemmod/releases/tag/v0.9.0-test.2).
Он проверяет именно опубликованный JAR, а не dev-среду. Отмечайте каждый пункт
как «пройдено», «не пройдено» или «не применимо».

## 1. Чистая установка

1. Сделайте копию проверяемого мира и папки `mods`.
2. Используйте **Minecraft 1.21.1** с **NeoForge 21.1.251**. Для запуска Minecraft
   нужен Java 21.
3. В папке `mods` удалите все старые `chemmod-*.jar`. Одновременно должен
   находиться только один JAR с mod id `chemmod`.
4. Скачайте из prerelease оба файла:
   - `chemmod-0.9.0-test.2.jar`;
   - `chemmod-0.9.0-test.2.jar.sha256`.
5. При желании проверьте контрольную сумму в той же папке:

   ```bash
   # Linux
   sha256sum -c chemmod-0.9.0-test.2.jar.sha256

   # macOS
   shasum -a 256 -c chemmod-0.9.0-test.2.jar.sha256
   ```

   В PowerShell можно сравнить вывод
   `Get-FileHash .\chemmod-0.9.0-test.2.jar -Algorithm SHA256` с первой колонкой
   `.sha256`-файла.
6. Запустите игру, создайте новый тестовый мир с включёнными командами либо
   получите OP на сервере. ChemMod должен появиться в списке модов, без crash
   при старте.

Сначала полезно проверить JAR **без Create**. Затем, если в вашем экземпляре
есть Create 6.0.10, отдельно повторите запуск с ним: Create является
необязательной интеграцией, а не обязательной зависимостью ChemMod.

## 2. Быстрый smoke-test химического ядра

В мире с командами выполните:

```text
/chem test
/chem lookup CCO
/chem lookup OCC
/chem lookup COC
/chem balance C2H5OH + O2 -> CO2 + H2O
/chem catalog
```

Ожидания:

- `/chem test` сообщает об успешной самопроверке, формуле этанола `C2H6O`,
  молярной массе около `46.069 g/mol` и сохранённой реакции горения;
- `CCO` и `OCC` дают одинаковый canonical ID;
- `CCO` и `COC` имеют одинаковую формулу, но разные canonical ID; у этанола
  расчётная температура кипения около `64 °C`, у диметилового эфира около
  `-2 °C`;
- balance выводит `C2H6O + 3 O2 -> 2 CO2 + 3 H2O`;
- catalog завершается без ошибки и показывает загруженные процессы материалов.

Команды `lookup`, `balance` и `test` ничего не записывают в discovery и не
создают игровой реактор. Это диагностический слой, а не игровой путь синтеза.

## 3. Колбы и явная смесь — основной тест v0.9.0-test.2

### Получение образцов

Самый простой способ — открыть creative-вкладку **ChemMod**. В ней есть пустая
колба, чистые эталонные колбы и калибровочная смесь воды с этанолом. Альтернатива
для оператора:

```text
/chem give вода
/chem give этанол
/chem give кислород
```

Нажмите `F3+H`, чтобы включить расширенные подсказки.

### Проверка готовой калибровочной смеси

1. Возьмите во вкладке ChemMod колбу со смесью воды и этанола.
2. Наведите на неё курсор.
3. Ожидайте заголовок «явная смесь», два компонента, формулы `H2O` и `C2H6O`,
   по `1.000000 mol`, всего `2.000000 mol`.
4. При `F3+H` должны появиться canonical keys компонентов.
5. Переложите колбу в инвентарь/сундук, выйдите из мира и войдите снова.
   Состав, количества и подсказка не должны измениться.

### Ручное точное смешивание

В survival-режиме положите **ровно одну** заполненную колбу в главную руку и
**ровно одну** заполненную колбу в дополнительную руку. Присядьте и используйте
одну из колб (обычный ПКМ в воздух). Операция сначала рассчитывает весь
результат и только затем меняет обе колбы.

| Входы | Ожидаемый результат |
|---|---|
| `1 mol` чистой воды + `1 mol` чистого этанола | в использованной руке смесь из `H2O 1.000000 mol` и `C2H6O 1.000000 mol`; в другой руке пустая колба |
| `1 mol` воды + `1 mol` воды | одна чистая водная колба с `2.000000 mol`, а не смесь из двух одинаковых записей; другая колба пустая |
| полученная смесь + ещё `1 mol` воды | явная смесь из двух identities: воды `2.000000 mol` и этанола `1.000000 mol`; всего `3.000000 mol` |

Смешивание само по себе **не** должно создать discovery, запустить реакцию,
выдать продукты или потерять компонент, который не участвует в будущем
планировщике реакции.

### Отрицательные проверки

1. Поместите стопку из двух одинаковых наполненных колб в одну руку и одну
   наполненную колбу в другую. При попытке смешать ожидается сообщение о том,
   что нужна одна колба в каждой руке; содержимое не должно измениться.
2. Пустой колбой возьмите пробу из исходного блока воды. Такая проба содержит
   измеренные игровые примеси и не является чистой молекулярной порцией.
   Попробуйте смешать её с эталонной чистой колбой: ожидается отказ «нельзя
   безопасно смешать», обе входные колбы остаются без изменений.
3. Повторите успешное смешивание на dedicated server и проверьте вторым клиентом
   tooltip этой же колбы. Количество и список компонентов должны совпасть у
   сервера и клиента.

## 4. Регрессия ранее реализованного контента

Это не новая химическая реакция. Для короткой проверки того, что M2 не сломал
остальные границы, дополнительно:

- нажмите ПКМ пустой колбой по исходнику воды и проверьте профиль/примеси в
  tooltip;
- выполните `/chem catalog` и убедитесь, что материальный каталог валиден;
- в creative убедитесь, что присутствуют медные формы, ступка, промывочная
  установка, сепаратор, печь и инструменты;
- если Create 6.0.10 установлен, убедитесь, что игра запускается и compat-контент
  виден; если Create отсутствует, ChemMod всё равно должен запускаться.

Подробные исторические проверки материального маршрута и Create находятся в
[`docs/handover/2026-10-05-chemmod-m5-create-pack-audit.md`](../handover/2026-10-05-chemmod-m5-create-pack-audit.md).

## 5. Что пока не является багом

В этой версии отсутствуют пользовательский реактор, запуск реакции из смешанной
колбы, автоматическая discovery-запись, разделение смеси, фазы и равновесие.
Сообщение об отказе смешать нечистую водную пробу — ожидаемое сохранение массы,
а не ошибка: для её примесей ещё нет явного молекулярного состава.

## 6. Что приложить к отчёту

Для каждого дефекта приложите:

1. точную версию JAR и значение SHA-256;
2. Minecraft/NeoForge/Java версии и полный список модов;
3. singleplayer или dedicated server, а также наличие Create/TFC;
4. пошаговые действия и ожидаемый/фактический результат;
5. скриншот tooltip обеих колб до и после операции;
6. `logs/latest.log` и crash-report, если игра завершилась аварийно.
