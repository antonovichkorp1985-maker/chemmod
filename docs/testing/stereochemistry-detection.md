# Стереохимия: что выводится из графа, а что надо сообщить

Решение — [`../adr/0005-geometry-derived-configuration-in-graph.md`](../adr/0005-geometry-derived-configuration-in-graph.md).
Здесь — что именно реализовано, чем проверено и чего нет.

Код: `core/src/main/kotlin/.../core/stereo/Stereochemistry.kt`.

## 1. Три вопроса, и ответы на них разные

| Вопрос | Ответ модели |
| --- | --- |
| Есть ли вообще выбор — существуют ли два расположения? | **выводится**, `stereocentres`, `stereogenicDoubleBonds` |
| Какое из двух у тебя? | **не выводится**, поля чётности ещё не добавлены |
| Выживает ли выбор, или расположения перетекают? | **частично выводится**: элемент (инверсия), π-связь, кольцо; стерика — только как величина |

## 2. Что реализовано

**`stereocentres(graph)`** — sp³-атомы с четырьмя разными заместителями.
Симметрия решается совпадением морган-меток: два метила изопропанола дают
одинаковую метку, две кольцевые ветки циклогексанола — тоже, поэтому ни тот, ни
другой углерод центром не является. Перебора путей нет.

**`stereogenicDoubleBonds(graph)`** — двойная связь с двумя разными
заместителями на каждом конце. Кольцевая связь считается, только если кольцо
вмещает транс-форму:

```kotlin
const val SMALLEST_STABLE_TRANS_CYCLOALKENE = 8
```

Порог не круглый и не выдуманный: транс-циклогексен — только предполагаемый
интермедиат, транс-циклогептен детектирован с временем жизни в секунды,
транс-циклооктен — наименьший routinely выделяемый. Размер кольца считается как
кратчайший путь между концами связи при снятой самой связи.

**`pyramidalChiralityCentres`** и **`rapidlyInvertingCentres`** — барьер инверсии
это свойство элемента. Азот: ~25 кДж/моль, аммиак 4·10¹⁰ раз в секунду → амин с
тремя разными группами хирален, но это одно вещество. Фосфор: ~130 кДж/моль →
энантиомеры стоят. Ряд — группа 15 (N, P, As, Sb, Bi); халькогены не берутся,
потому что трёхкоординатны только как катионы, а таблица валентностей выдала бы
нейтральной трёхсвязной сере неявный водород.

**`hinderedRotationCandidates(graph)`** — одинарная связь между двумя
ароматическими кольцами плюс число тяжёлых атомов на орто-положениях. Бифенил
даёт 0 и вращается свободно, 2,2'-диметилбифенил — 2.

**Порог сознательно не ставится.** Граница между «перетекает» и «выделяется» —
барьер около 22–25 ккал/моль (критерий Оки: t½ > 1000 с), а перевод ортовой
нагруженности в барьер требует измеренных данных, которых в репозитории нет.
Сообщить величину, которую такое правило потребляет, — честно; придумать отсечку
— нет.

## 3. Как проверить руками

```kotlin
val g = Molecule.fromSMILESlike("CC(O)CC").graph      // 2-бутанол
Stereochemistry.stereocentres(g)                      // [1]
Stereochemistry.stereogenicDoubleBonds(
    Molecule.fromSMILESlike("C1=CCCCCCC1").graph)     // транс-циклооктен: 1 связь
Stereochemistry.rapidlyInvertingCentres(
    Molecule.fromSMILESlike("CN(CC)CCC").graph)       // [1] — амин, инвертирует
```

## 4. Дыры

- **Полей чётности нет.** Цис- и транс-2-бутен по-прежнему одно вещество,
  *(R)*- и *(S)*-2-бутанол тоже. Это единственная невыводимая часть, и она идёт
  вместе с версией дайджеста — соглашение записано в ADR-0005, раздел «The parity
  convention».
- **Барьера нет ни для чего.** Атропоизомерия распознаётся как кандидат с
  величиной, но не как решение. Инверсия азота — да, потому что там правило по
  элементу; стерика у биарилов — нет.
- **Дескриптор «три разных заместителя» не видит дейтерий.** Заместитель CH₃ и
  заместитель CH₂D различаются изотопом, а изотоп в графе не представляется —
  `Atom` несёт элемент, не нуклид.
- **Конформеры не моделируются вовсе**, и это намеренно: они не разные вещества.
  Но значит и «наиболее выгодная конформация» нигде не считается, а без неё
  координат для отрисовки не собрать.

## 5. Тесты

`core/src/test/.../stereo/StereochemistryTest.kt` — 10 тестов: центр из четырёх
разных заместителей; два одинаковых заместителя центр гасят; кольцевая симметрия
гасит центр без перебора путей (с проверкой, что метки двух кольцевых ветвей
совпадают); двойная связь стереогенна только при разных концах; кольцевая двойная
связь считается только с восьмого кольца; биарильная ось с ортовой
нагруженностью; нагруженность измеряется, но отсечка не выдумана; пирамидальный
атом с тремя разными группами; азот инвертирует, фосфор нет; модель не выдумывает
центров там, где их нет.
