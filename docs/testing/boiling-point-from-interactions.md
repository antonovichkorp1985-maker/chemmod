# ChemMod — точка кипения из взаимодействий, а не из строки про воду

**Дата:** 10 октября 2026
**Тип среза:** свойство. Одна запись вещества в данных найдена, помечена и заперта тестом.

## 1. Что было не так (проверено в репозитории)

`chemmod/properties/default.json` содержал блок

```json
"boiling": { "exactFormulaCelsius": {"H2O": 100.0}, ... }
```

то есть вода кипела при 100 °C потому, что это было **записано**, а не потому, что модель знала про
водородные связи. Это ровно та «таблица веществ», которой проект не должен быть.

Вторая проблема оказалась хуже. Углеводородная ветка
`−161.5 + 48·(C−1) − 3.5·(C−1)(C−2)` расходилась с опытом так:

| Алкан | Опыт, °C | Старая модель | Ошибка |
| --- | --- | --- | --- |
| метан | −161.5 | −161.5 | 0.0 |
| этан | −88.6 | −113.5 | −24.9 |
| пропан | −42.1 | −72.5 | −30.4 |
| бутан | −0.5 | −38.5 | −38.0 |
| пентан | 36.1 | −11.5 | −47.6 |
| гексан | 68.7 | 8.5 | −60.2 |
| гептан | 98.4 | 21.5 | −76.9 |
| октан | 125.6 | 27.5 | **−98.1** |

Спиртовая ветка `65 − 1·(C−1)` давала пропанол 63 °C (опыт 97) и бутанол 62 °C (опыт 118).
То есть модель была «точной» только в тех точках, где её подогнали.

## 2. Что стало

**Углеводороды, циклы, арены** — дисперсия по молярной массе плюс поправки на цикл и ароматику:

```
Tb = −242.88 + 15.71·M^(2/3) + 22.89·rings + 8.93·aromaticRings
```

Подгонка по 21 соединению (алканы C1–C10, алкены, циклоалканы C3–C6, бензол, толуол, этилбензол):
**RMS 6.3 K**, худшая точка — метан (+18.6 K). Октан вместо −98 K теперь +1.5 K, гексан −5.0 K,
циклогексан и бензол из `null` стали 81.7 и 76.0 °C при опыте 80.7 и 80.1.

Ветвь работает **только для соединений из C и H** — это и есть её область подгонки. Всё остальное
получает `null` и `basis = no-model:fit-covers-hydrocarbons-only` (§4, пункт 1).

**Спирты и полиолы** — та же дисперсия плюс водородная сеть:

```
Tb = −84.66 + 7.02·M^(2/3) + 3.72·Н-сеть
```

где Н-сеть = энергия пар донор/акцептор, посчитанная из графа (`min(доноры, акцепторы)`, энергия
пары зависит от элементов: O···O 21, N···N 13, F···F 29 кДж/моль). Подгонка по 8 спиртам:
**RMS 7.4 K**.

| Вещество | Опыт, °C | Модель | Ошибка |
| --- | --- | --- | --- |
| метанол | 64.7 | 64.3 | −0.4 |
| этанол | 78.4 | 83.7 | +5.3 |
| пропанол | 97.2 | 101.2 | +4.0 |
| бутанол | 117.7 | 117.3 | −0.4 |
| этиленгликоль | 197.3 | 181.6 | −15.7 |
| глицерин (вне подгонки) | 290.0 | 292.9 | +2.9 |

Этиленгликоль (62 г/моль) теперь кипит выше гексана (86 г/моль) именно из-за четырёх сайтов,
а глицерин с шестью сайтами и сетью 63 кДж/моль попадает в 290 °C, хотя в подгонке его не было.

**Эфиры** потеряли собственные две константы и идут через дисперсионную ветку: диметиловый эфир
−41.0 °C (опыт −24.8), диэтиловый 27.6 (опыт 34.6). Разница изомеров этанол/диметиловый эфир
теперь 125 K и объясняется сетью, а не подбором.

**Каждое значение сообщает, откуда оно взялось** — поле `PredictedProperties.boilingPointBasis`
и строка в `chem lookup`:

```
Boiling point:     83.7 °C (hydroxyl-family+hydrogen-bond-network)
Boiling point:     100.0 °C (calibration-anchor:H2O)
```

## 3. Долг заперт тестом

Строка про воду осталась: без неё вода стала бы `null`, а это хуже для игрока. Но теперь

- значение помечено как `calibration-anchor:H2O`, и CLI это печатает;
- `BoilingPointModelTest.the anchor list is not allowed to grow` падает, если в
  `exactFormulaCelsius` появится вторая запись.

Дальше этот список должен только уменьшаться.

## 4. Что пробовал и отверг

Четыре общие формы модели на 33–37 эталонных соединениях (алканы, алкены, арены, циклы, спирты,
эфиры, амины, вода, аммиак, HF, HCl, галогенпроизводные):

| Форма | RMS | Худшие точки |
| --- | --- | --- |
| линейная, `√M` + ветви | 27.8 K | метантиол +76, азот −74 |
| линейная, `M^(2/3)` + nC + сеть | 14.7 K | метан +39, метанол −33 |
| линейная, `M^(2/3)` + кольца + сайты | 15.4 K | метан +42, метанол −36 |
| Трутон: `Tb = 1000·ΔH/(S₀ − S₁/M)` | 19.1 K | CCl₄ +44, метанол −40 |

Общая модель не сходится по двум причинам, и обе — отсутствующая физика, а не плохие коэффициенты:

1. **Дисперсия считается по массе, а надо по поляризуемости.** Ошибка не «+28 K», как было
   написано в первой версии этого документа, а на порядок больше. Пересчёт отправленных
   коэффициентов против опыта (этот срез, 10 октября):

   | Вещество | Опыт, °C | Масса-модель | Ошибка |
   | --- | --- | --- | --- |
   | CF₄ | −128.0 | +67.9 | **+195.9** |
   | CH₃I | 42.4 | 184.6 | **+142.2** |
   | CCl₄ | 76.7 | 208.1 | **+131.4** |
   | CH₃Br | 3.6 | 84.1 | +80.5 |
   | CHCl₃ | 61.2 | 138.0 | +76.8 |
   | CH₂Cl₂ | 39.6 | 60.7 | +21.1 |
   | CH₃Cl | −24.2 | −28.3 | −4.1 |
   | CH₃F | −78.4 | −77.9 | +0.5 |
   | ацетонитрил | 81.6 | −55.9 | **−137.5** |
   | нитрометан | 101.2 | 0.7 | −100.5 |
   | метиламин | −6.3 | −87.7 | −81.4 |
   | анилин | 184.1 | 111.7 | −72.4 |
   | ацетон | 56.1 | −7.3 | −63.4 |
   | этиламин | 16.6 | −43.9 | −60.5 |
   | метантиол | 5.9 | −35.1 | −41.0 |
   | пиридин | 115.2 | 78.4 | −36.8 |
   | диэтиловый эфир | 34.6 | 34.3 | −0.3 |
   | диметиловый эфир | −24.8 | −41.0 | −16.2 |

   **Поляризуемость как свойство элемента добавлена** (23 элемента, `polarizibilityCubicAngstroms`
   в `elements.json`: список атомов CCCBDB, Miller & Bederson 1977, для H…Kr и Miller 1990 для I).
   Аддитивность работает: Σα для CCl₄ = 10.48 Å³ при измеренных 10.002 Å³ для молекулы (4.8 %).
   Свойство выводится в `PredictedProperties.polarizibilityCubicAngstroms` и печатается в
   `chem lookup`; там, где значения нет (например Fe), оно `null`, а не ноль.

   **Что проверено и отвергнуто как замена массы** (подгонка по 28 веществам: алканы C1–C10,
   алкены, циклоалканы C3–C6, бензол/толуол/этилбензол, 8 галогенпроизводных):

   | Дескриптор | RMS, K | Худшая точка |
   | --- | --- | --- |
   | `M^(2/3)` + кольца + ароматика (отправлено) | 43.8 | CF₄ +157.8 |
   | `Σα` + кольца + ароматика | 42.2 | метан +94.5 |
   | `(Σα)^p`, лучший p = 0.40 | 39.4 | CHCl₃ +79.5 |
   | `Σ α_i^(2/3)` | 46.9 | метан +104.0 |
   | `M^(2/3)` + `Σα` + кольца + ароматика | 25.1 | CF₄ +97.8 |
   | `M^(2/3)` + кольца + ароматика + по элементу F/Cl/Br/I | **13.1** | CH₃F +36.9 |

   Последняя форма лучше всех, но это таблица поправок на элемент, а не физика: коэффициенты
   отрицательны (F −47, Cl −26, Br −81, I −137 K) и лишь гасят перевес массы. При этом метан
   ухудшается с +18.6 до −31.8 K, а CH₃F остаётся +36.9. Поэтому она не поехала: вместо неё
   дисперсионная ветвь ограничена своей областью подгонки, а C/H-соединения остались при RMS 6.3 K.
   Настоящая замена массы — это не `Σα`, а элементный вклад в C6 (поляризуемость × энергия
   ионизации): у фтора α мала, а I велика, и один степенной закон этого не передаёт.
2. **Водородная сеть считается как `min(доноры, акцепторы)`, без насыщения и геометрии.** Спирт
   образует цепи, вода — трёхмерную сетку, и на испарение уходит не одна «средняя» связь. Поэтому
   метанол и HF не описываются одним коэффициентом: метанол −36…−43 K, HF +16…+42 K.

Поэтому общий пересчёт **не поехал в репозиторий**: он ухудшил бы метан и метанол. Поехали две
ветки, где модель реально выигрывает, и честная маркировка всего остального.

## 5. Известные дыры (не спрятаны, а названы)

- Вода — калибровочная точка (см. §3).
- Аммиак, HF, HCl и остальные безуглеродные вещества вне якоря получают `null` и
  `basis = no-model`, а не выдуманное число.
- Всё, что содержит не только C и H и не является спиртом/полиолом, теперь тоже `null`
  (`no-model:fit-covers-hydrocarbons-only`). За это пришлось отдать два приличных числа —
  диэтиловый эфир (−0.3 K) и диметиловый эфир (−16.2 K): правило, которое пускает их, пускает и
  ацетонитрил с ошибкой −137.5 K.
- Нужны отдельные ветви: доноры N–H (метиламин −81.4 K), карбонилы и нитрилы (−63…−137 K),
  галогениды через элементный C6 (+76…+196 K). Общая подгонка спиртов с аминами даёт RMS 22.6 K,
  поэтому ветви должны быть раздельными.

## 6. Проверка

- `core/properties/BoilingPointModelTest.kt` — 10 тестов: якорь воды помечен и не может расти,
  алканы/циклы/арены по дисперсии, спирты растут с сетью, диол тяжелее гексана по кипению,
  глицерин вне подгонки, семейства вне области подгонки получают отказ, поляризуемость считается
  из данных элементов (CCl₄ 10.48, метан 4.43, железо `null`), коэффициенты положительны.
- Обновлены `MoleculeTest` (этанол 83.7, диметиловый эфир −41.0, метанол 64.3, циклопропан −29.9
  вместо `null`) и `scripts/smoke-test.sh` (строка `chem lookup CCO`).
- Исполняет CI (прогон 38085966837, `classes=28 tests=178 failures=0 errors=0`); локально JDK нет.
  Шаг «Build and test» прогоняет и `scripts/smoke-test.sh`, который проверяет точную строку
  `Boiling point:     83.7 °C (hydroxyl-family+hydrogen-bond-network)` — то есть путь
  данные → модель → CLI проверен целиком, а не только юнитами.
