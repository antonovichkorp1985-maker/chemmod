# ChemMod v1.0.2-test.2 — owner test checklist

Minecraft 1.21.1 · NeoForge 21.1.251 · Java 21. Back up the world first. Install the exact same JAR on server and every client. This checklist does not itself close a milestone.

Verify `chemmod-1.0.2-test.2.jar.sha256` before installation. If anything fails, keep the client/server logs and report the exact step, versions, mod list and checksum.

## 1. Launch, localization and M2/A2 reference samples

1. Start the actual modpack on the dedicated server and clients. Check for registry, component, attachment, resource and codec errors.
2. In creative, find the Chemical Reference Book and the molecular samples. Confirm samples correspond to authored rule participants/products (for example water, ethanol, oxygen, acetaldehyde and acetic-acid pathway products), not a wholesale list of every name-directory or test-only structure. Catalyst coupons and other material/catalyst forms should remain material items, not molecular vials.
3. Repeat the following in English and Russian:
   - Hold the book in one hand and a filled single-substance reaction sample in the other.
   - Sneak-use the book. Confirm the report is shown and neither book nor vial amount/components change.
   - Repeat with the book in the other hand.
   - Use the book without sneaking; ordinary use should not be intercepted.
4. Check report fields against `chem lookup` for the same graph: formula, molar mass, any available boiling-point estimate and basis, combustion estimate, modeled solubility result when one exists, and model/structural flags.
5. Confirm a neutral reference such as water does **not** display an invented solubility label. Structural flags must carry the explicit warning that they are not a toxicity or safety assessment.
6. Try an empty vial, a mixture vial, and (if available) a valid single-substance graph that is outside the reaction-derived set. Each should give a clear message and leave both held items unchanged. The book is not an arbitrary-graph designer.
7. Inspect vial tooltips: unknown solubility must be omitted rather than printed as `UNKNOWN`.

## 2. M2 transfer and persistence

Follow [`m2-vial-steel-flask-source.md`](m2-vial-steel-flask-source.md). Verify exact ethanol amount transfer, empty source vial, unchanged total moles, holder behavior, RU/EN strings, save/restart, and client/server agreement. Do not treat the steel flask as an A4 capacity/compatibility model.

## 3. M3 reactor and prepared catalyst

Follow [`m3-reactor-source.md`](m3-reactor-source.md). For ethanol dehydrogenation, use the prepared `copper_catalyst_coupon`; an ordinary copper ingot is the negative control. Check GUI, progress, exact acetaldehyde + hydrogen output, refusal without heat/catalyst, save/restart and a second client. The Cu(110) coupon supports only the stated ethanol-dehydrogenation surface model; it does not validate the separate acetic-acid pathways.

## 4. M4 graph gas test path

Use a disposable world and the operator-only commands described in [`m4-graph-gas-reactions.md`](m4-graph-gas-reactions.md). Verify permissions, chlorine graph retention/settling/visibility, save/restart and balanced H2/O2 → H2O after the same-cell ignition trigger. No chlorine debuff, mask/filter, room fan, tank leak, validated hydrogen flammability envelope or explosion is implemented; record these as absent, not as C1/C2 passes. The ignition cell's 500 K gate is not a temperature measurement.
