## Unit Tests (Core Module)

### ElectricalNetworkTest
- `testTransformerStepUp`: V2/V1 = N2/N1 for step-up transformer
- `testTransformerStepDown`: V2/V1 = N2/N1 for step-down transformer
- `testTransformerPowerConservation`: P_primary ≈ P_secondary (within 1%)
- `testTransformerImpedanceReflection`: Z_primary = Z_secondary / n²
- `testTransformerCenterTap`: Center-tap voltage splitting (V/2 on each half)
- `testTransformerLoadReflection`: Load impedance reflected to primary
- `testTransformerMultipleSecondaries`: Multi-tap transformer with independent secondaries
- Existing tests: resistor network, voltage source, ground reference, multi-subgraph, floating nodes

### BlastShockwaveModelTest
- `testNormalReflectionCoefficientAcousticLimit`: Cr -> 2.0 as ΔP -> 0
- `testNormalReflectionCoefficientStrongShock`: Cr -> 8.0 as ΔP -> ∞ (monotonically)
- `testNormalReflectionCoefficientMonotonic`: Cr increases monotonically with ΔP
- `testComputeOverpressure`: Peak overpressure at various scaled distances
- `testComputeArrivalTime`: Arrival time vs distance
- `testComputeWilsonCloud`: Wilson cloud formation threshold
- `testFromTntMass`: TNT equivalent source creation
- `testFromFuelAir`: Fuel-air source creation

### WorldGasFieldTest (proposed - verify stoichiometry)
- `testIgniteVolumetricCloud`: Cloud ignition consumes fuel + O2, produces CO2 + H2O
- `testIgniteVolumetricCloudNoO2`: Returns false when no O2 available
- `testIgniteVolumetricCloudNoFuel`: Returns false when no fuel in cloud
- `testAmbientGasApiBlastWind`: Dynamic blast wind from active sources
- `testAmbientGasApiTotalDensity`: Ambient + cloud density at position
