## 1. CM-2a: pressure relief valve and manual vent

1. `ClosedVessel(volume, wallStrength)` requires positive wall strength; zero or negative throws.
2. `bursts(wallStrengthPascals)` returns true only when pressure exceeds the given wall strength.
3. `releaseAtPressure(threshold)` returns 0 when pressure is at or below threshold; positive moles released when above; pressure after release is at or near threshold.
4. `ventMoles(requested)` removes gas proportionally from all species; returns min(requested, available).
5. `empty()` removes all moles; `species()` is empty afterwards.

## 2. CM-2c: inhalation exposure and respirator filter

1. `RespiratorFilter(capacityMicromoles)` starts with full remaining capacity equal to capacity.
2. `adsorb(amount)` within capacity decrements remaining capacity; returns new filter instance (immutable).
3. `adsorb(amount)` exceeding remaining capacity returns null (filter saturated).
4. Zero-capacity filter rejects all adsorption.
5. Chained adsorptions accumulate consumed micromoles correctly.

## 3. CM-1: ionic exchange (metathesis) and solubility table

1. Confirm `Phase.hasFreeMobileIons`: AQUEOUS/MOLTEN true; SOLID/GAS false.
2. Confirm phase gate: only AQUEOUS/MOLTEN permit ion exchange; SOLID/GAS → NO_FREE_IONS.
3. Test precipitate formation (Ag⁺ + Cl⁻ → AgCl): PROCEEDS in AQUEOUS.
4. Test gas-forming (H⁺ + CO₃²⁻ → CO₂ + H₂O): gas outcome PROCEEDS.
5. Test neutralization (H⁺ + OH⁻ → H₂O): weak electrolyte outcome PROCEEDS.
6. Confirm NH₄⁺ hydroxide gas formation (PROCEEDS).
7. Confirm fully soluble product pairs yield NO_DRIVING_FORCE outcome.
