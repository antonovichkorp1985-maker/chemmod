## 1. ElectricalNetworkSolver (Kirchhoff G * V = I)

1. Single resistor across voltage source: V = I * R (Ohm's law).
2. Two parallel resistors: total current splits equally; equivalent resistance = R/2.
3. Voltage divider: midpoint voltage ≈ half supply; KVL around loop holds.
4. Floating node: finite voltage, not NaN/Infinity.
5. Open circuit: no current, all node voltages finite.
6. Multiple isolated subgraphs: each solves independently; ground node stays exactly 0 V.
7. Cable segment as resistor: R = rho * L / A (copper rho = 1.68e-8 ohm*m).
8. Voltage source internal resistance: terminal voltage sags under load.

## 2. CableSegment melting + fuse

1. Thin lead segment (T_melt = 600.61 K) melts at lower current than thick copper bus (T_melt = 1357.77 K).
2. Melted segment transitions to OPEN_MELTED (conductivity = 0).
3. Bare wet conductor has ground-fault conductance > 0; dry insulated conductor = 0.
4. Overvoltage breaches insulation: INSULATED -> BREACHED.
5. Breached wet conductor has ground-fault path to earth (V = 0 V node).

## 3. GalvanicCellModel (Nernst/Faraday)

1. Daniel cell Cu/Zn: EMF ~1.10 V (z=2).
2. Lead-acid cell PbO2/Pb: EMF ~1.59 V (z=2).
3. Unknown electrode pair: returns null (NO_MODEL), never invented.
4. Faraday's law: dn/dt = I / (z * F); doubling current doubles moles/second; F = 96485.33212 C/mol.
5. Zero electrons: returns null.

## 4. SparkIgnitionEvaluator

1. H2 + O2 mixture within flammability limits: spark >= MIE (0.017 J for H2) ignites.
2. Spark below MIE: no ignition.
3. N2 + O2 (no combustible fuel): no ignition.
4. H2 without O2 (no oxidizer): no ignition.
5. Empty gas: no ignition.
6. Short-circuit spark energy: E = V * I * t.
7. Capacitor spark energy: E = 0.5 * C * V^2.
