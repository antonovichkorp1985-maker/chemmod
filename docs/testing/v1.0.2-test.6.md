## 1. Block mass API (Aeronautics Plus Centre of Mass)

1. `MaterialDensityRegistry.withDefaults()` contains copper 8960, steel 7850, aluminium 2700 kg/m³.
2. `BlockMassApi.solidBlockMassKilograms(registry, "chemmod:copper")` == 8960.0 kg/m³.
3. `BlockMassApi.hollowBlockMassKilograms()` with packingFactor 0.5 returns half the solid mass.
4. `BlockMassApi.gasTankTotalMassKilograms()` increases as gas is added to the ClosedVessel (heavier tank).
5. Unregistered material returns null (NO_MODEL), never an invented value.

## 2. AmbientGasApi (WorldGasField)

1. `WorldGasField.AMBIENT.pressurePascalsAt(0.0)` ≈ 101325 Pa.
2. `WorldGasField.AMBIENT.densityKilogramsPerCubicMetreAt(0.0)` ≈ 1.225 kg/m³.
3. Pressure and density decrease with altitude; at 11 km ≈ 22632 Pa / 0.364 kg/m³.
4. `isVacuum()` returns true when pressure below threshold (high altitude).
5. Temperature follows ISA lapse rate below tropopause, isothermal above.

## 3. E0 Catenary cables (no redstone)

1. `CatenaryMath.solveParameter()` for 10m span / 11m cable / 1 N/m returns non-null result.
2. Cable shorter than span returns null (NO_MODEL).
3. `heightAt(0)` and `heightAt(span)` == 0; midpoint below supports.
4. Tension minimum at midpoint, maximum at supports.
5. Heavier cable: same sag, more tension (for same span and length).
6. `CableSegment`: BARE shorts when wet/grounded; INSULATED does not short dry.
7. `CableSegment`: overvoltage breaches insulation; over-temperature melts insulation.
8. Joule heating scales with I²: double current → 4× heat.
9. New blocks `cable_terminal_bare` and `cable_terminal_insulated` place without redstone references.

## 4. No redstone

1. Grep codebase for "redstone" — zero matches in ChemMod source.
2. All gas/ventilation/valve mechanics use pressure/temperature differentials or manual control only.
