# ChemMod — поляризуемость атома как свойство элемента

**Дата:** 11 октября 2026
**Тип среза:** данные. Одно свойство заполнено для всей таблицы из одного источника; пробел
остаётся пробелом, а не нулём.

## 1. Что было не так

`polarizibilityCubicAngstroms` было заполнено у 23 элементов из 118 — H…Kr плюс I, из двух
разных подборок (CCCBDB, Miller & Bederson 1977 / Miller 1990). Остальные 95 давали `null`,
и `FormulaCalculator.polarizibilityCubicAngstroms` возвращал `null` для **любой** молекулы,
где встречается переходный металл, лантаноид, актиноид или тяжёлый p-элемент: у `[Fe]`,
у ферроцена, у любого уранового соединения. Дескриптор, который должен был заменить массу в
дисперсионном члене, нельзя было ни подобрать, ни проверить — он просто не считался.

## 2. Источник — один

Рекомендованная колонка рисунка 1 («Recommended values from Table 1 for the atomic
polarizabilities (atomic units; estimated uncertainties in parentheses) of elements
Z = 1-120») работы:

> P. Schwerdtfeger, J. K. Nagle, «2018 Table of static dipole polarizabilities of the neutral
> elements in the periodic table», *Mol. Phys.* **117** (2019) 1200–1225,
> <https://doi.org/10.1080/00268976.2018.1535143>; обновлённая таблица:
> <https://ctcp.massey.ac.nz/2018Tablepol.pdf>

Перевод единиц взят из того же документа: **1 a.u. = 0.14818471 Å³**. В JSON пишется
`α[Å³] = α[a.u.] · 0.14818471`, округлённое до трёх знаков.

Один источник — не эстетика. Разброс между подборками одной и той же величины доходит до
фактора 2.4: для Pd рекомендованное значение здесь 26.14 ± 0.10 a.u. (замкнутая оболочка
4d¹⁰), тогда как в компиляции коэффициентов C₆ стоит 61.7; для Po 44 против 36.1, для At 42
против 30.4. Смешивать такие шкалы в одном поле — значит заложить в данные шум больше, чем
сами поправки, которые по ним считают.

## 3. Что сверено вручную

Рисунок 1 — сводка по Table 1, и каждая доступная ячейка сверена с её же строкой
«recommended»:

| Z | Элемент | Table 1 | Рисунок 1 |
| --- | --- | --- | --- |
| 34 | Se | 28.9 ± 1.0 | 29(1) |
| 35 | Br | 21 ± 1 | 21(1) |
| 36 | Kr | 16.78 ± 0.02 | 16.8(0) |
| 39–45 | Y…Rh | 162 / 112 / 98 / 87 / 79 / 72 / 66 | те же |
| 46 | Pd | 26.14 ± 0.10 | 26.1(1) |
| 47 | Ag | 55 ± 8 | 55(8) |
| 70 | Yb | 139.3 ± 5.9 | 139(6) |
| 71–78 | Lu…Pt | 137 / 103 / 74 / 68 / 62 / 57 / 54 / 48 | те же |
| 79 | Au | 36 ± 3 | 36(3) |
| 80 | Hg | 33.91 ± 0.34 | 33.9(4) |
| 81–85 | Tl…At | 50 / 47 / 48 / 44 / 42 | те же |

Немонотонность `Bi 48 > Pb 47` и `Po 44 > At 42` — это значения самого источника, а не сдвиг
при переносе: обе строки Table 1 подтверждают их. Для золота похожая ловушка уже проверена:
45.4 a.u. в Table 1 есть, но это строка TD-DFT (LEXX), а рекомендовано 36 ± 3.

Для Z = 86–118 текст PDF обрывается (парсер читает первые ~30 страниц), поэтому:

* **Og = 58 ± 6 a.u.** подтверждён независимо — это значение Е. Jerabek et al. (2018),
  4c Dirac–Coulomb CCSD(T); на него же ссылается Smits et al., *Angew. Chem. Int. Ed.* 2020
  («the latest high-level value for the polarizability of α = 58 ± 6 a.u.»).
* **Cn = 28 a.u.** сходится с 27.92 a.u., использованными в расчётах рассеяния электронов.

## 4. Единственный пробел

**Livermorium (Z = 116) — без значения.** Сама работа пишет, что покрывает Z = 1–120,
«except for livermorium where we could not find a reliable value». Поле остаётся `null`:
`Element.polarizibilityCubicAngstroms` nullable, `FormulaCalculator` возвращает `null` для
молекулы с таким атомом, `PredictedProperties` печатает отсутствие, а не ноль. Проверка
`BoilingPointModelTest` ловит `[Lv]` насквозь через предиктор.

Итог: **117 значений, 1 документированный пробел**.

## 5. Воспроизводимость

```
python3 scripts/generate_element_polarizability.py
```

Скрипт хранит таблицу α_D в a.u. вместе с приведёнными погрешностями, переводит единицы,
переписывает `elements.json` построчно (по элементу на строку, порядок ключей не трогает) и
печатает свои проверки: покрытие Z = 1–118, отсутствие изменений в чужих полях,
положительность значений, тренды по группам 17/18 и по 3-му периоду, аддитивные суммы для
CCl₄ и CH₄. Запуск дважды подряд даёт идентичный файл.

## 6. Предел аддитивности — то, ради чего это поле нельзя читать как измерение

Сумма свободных атомов **не** равна поляризуемости молекулы:

| Молекула | Σα (аддитивно) | Измерено | Отклонение |
| --- | --- | --- | --- |
| CCl₄ | 10.326 Å³ | 10.002 Å³ | +3 % |
| CH₄ | 4.342 Å³ | 2.66 Å³ | **+63 %** |

Причина физическая: водород, связанный с углеродом, поляризуется намного слабее свободного
атома H — у него нет diffuse-облака. Для галогенидов ошибка мала, для гидридов огромна.
Поэтому Σα в ChemMod — **подгоночный дескриптор**, а не физическая величина: любая ветвь,
которая его использует, обязана нести собственный интерсепт.

Это же объясняет уже зафиксированный отказ: в `docs/testing/boiling-point-from-interactions.md`
дескриптор `Σα` + кольца + ароматика дал RMS 42.2 K при худшей точке «метан +94.5». Портит
метрику не Σα целиком, а вклад водорода в ней — худшая точка ровно та молекула, где водорода
больше всего на один тяжёлый атом.

## 7. Что это даёт дальше

* Поляризуемость считается для любой молекулы, кроме содержащих Lv: `[Fe]` = 9.187 Å³,
  `[U]` = 19.116 Å³, `[Th]` = 32.156 Å³.
* Дескриптор для ветви галогенидов теперь нужно строить с учётом п. 6: либо Σα по тяжёлым
  атомам плюс явный счётчик H, либо поэлементные слагаемые. Простая замена `M^(2/3)` на `Σα`
  уже отвергнута измерением.

## 8. Проверки в CI

* `ContentCoherenceTest.polarizability covers the periodic table except the element the source
  refuses` — единственный `null` это `Lv`; H = 0.667 и C = 1.674 (перевод единиц); рост вниз
  по группам 17 и 18 и спад вправо по 3-му периоду.
* `BoilingPointModelTest.polarizibility comes from element data, so halogens count for what
  they are` — CCl₄ 10.33, CH₄ 4.34, `[Lv]` → `null` через предиктор.
