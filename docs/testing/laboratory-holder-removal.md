## Поведение

- **Shift + ПКМ пустой основной рукой** по стойке или подносу снимает только
  выбранный держатель, если все его позиции пусты.
- Вторая часть в той же клетке, её ID и сосуды остаются на месте.
- Заполненный держатель не снимается: игрок получает просьбу сначала забрать
  сосуды. Это отказ без изменения сохранённого содержимого.
- После снятия последней пустой части host-блок исчезает. Предмет передаётся
  игроку, а при переполнении инвентаря выпадает рядом; второй экземпляр через
  onRemove не создаётся.
- Обычный ПКМ пустой рукой по-прежнему извлекает один сосуд.
- Снятый пустой держатель становится обычным предметом. Новая установка не
  сохраняет прежний ID; у оставшегося соседа идентичность сохраняется.

## Автоматические проверки

Четыре новых GameTests: пустая стойка рядом с заполненным подносом; отказ для
обеих заполненных частей с точным сравнением NBT; снятие последней части без
остаточного host и повторного выпадения; маршрут Shift-взаимодействия с игроком.
Запускаются общим `scripts/smoke-test.sh` / `:mod:runGameTestServer`.

## Ручная проверка после будущей сборки

Поставить обе части, заполнить одну, снять другую. Проверить GUI-подсказку,
содержимое соседа, сохранение/загрузку, повторную установку и двух клиентов.
Проверить извлечение обычным ПКМ, отказ для заполненной части и полный инвентарь.
CI не подтверждает реальный restart, client rendering или multiplayer.

Перенос заполненного подноса целиком, свободное размещение, поворот и снятие
держателя с сохранением его ID пока не реализованы. Нагреватели и вакуумное
оборудование остаются отдельными задачами; механика снятия не подменяет их.
