## 2. Operator-only gas-field command path

Run in a **disposable copy** as an operator. The names resolve through the finite bundled reference directory; arbitrary SMILES/graphs are not accepted by these commands.

- Put a known amount of chlorine in the cell containing the target player and inspect it:

  ```text
  /chem gas release @s chlorine 4
  /chem gas inspect @s
  ```

  Check whether particles are visible and whether the chlorine graph/amount can be inspected after movement to lower cells and after a save/restart. If testing open-sky dilution, do it outdoors and record the elapsed time. There is no room fan, chlorine health effect, mask/filter, or tank leak in this candidate; their absence is an expected gap, **not a C1 pass**.

- Negative ignition control: in a fresh, fire-free cell, add hydrogen and oxygen, wait at least one gas-field update (20 game ticks), then inspect:

  ```text
  /chem gas release @s hydrogen 2
  /chem gas release @s oxygen 1
  /chem gas inspect @s
  ```

  H2O should not appear without an ignition source. Use another fresh cell for the positive case.

- Positive chemistry case: in a disposable, fire-safe setup, add the same H2/O2 amounts. The command output reports the 4 m cell's block origin `(x, y, z)`. Use `originX+1`, `originY`, `originZ+1` as the netherrack coordinates and `originX+1`, `originY+1`, `originZ+1` as the fire coordinates; calculate those six coordinates before entering the commands. This puts a supported fire in the player's current 4 m gas cell without placing it on the player. After one or more field updates, inspect again. The current implementation should consume H2/O2 by the ordinary balanced rule and report H2O. A fire in another cell must not trigger this cell.

  ```text
  /chem gas release @s hydrogen 2
  /chem gas release @s oxygen 1
  /chem gas inspect @s
  /setblock <originX+1> <originY> <originZ+1> minecraft:netherrack
  /setblock <originX+1> <originY+1> <originZ+1> minecraft:fire
  /chem gas inspect @s
  ```

  **Do not expect or attempt to verify an explosion.** There is no implemented LEL gate, blast damage, or block-destruction model; these amounts do not represent a calibrated room concentration. The fire test is a rule-integration check only.

- Confirm that a non-operator cannot use `/chem gas`. Report command registration, RU/EN output, persistence, particle visibility, settling, and any crashes as separate pass/fail observations.

## 3. Explicit M4 limitations

This candidate only tests graph identity/persistence, sparse transport, tint and balanced in-cell reaction. It does not implement a chlorine damage/debuff effect, a gas mask/filter, powered ventilation, a tank leak, background-air storage, a validated hydrogen LEL/UEL envelope, explosion damage, or controlled block destruction. Do not mark full C1/C2 accepted based on these checks.
