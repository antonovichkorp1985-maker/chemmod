# ChemMod — классы соединений как вывод из графа

**Дата:** 11 октября 2026
**Тип среза:** свойство. Класс вещества выводится из связей, а не выбирается условиями внутри
модели свойств.

## 1. Что было не так

Модель кипения выбирала «семейство» двумя захардкоженными условиями внутри `predictBoilingPoint`:

```kotlin
val oxygenAtoms = graph.atoms.filter { it.element.symbol == "O" }
if (oxygenAtoms.isNotEmpty() && oxygenAtoms.all { isHydroxyl(graph, it.id) }) { ... }
if ((formula["C"] ?: 0) > 0 && formula.keys.all { it == "C" || it == "H" }) { ... }
```

Это работало, но понятия «класс» в ядре не было: спросить «это алкен?» было не у кого, а каждое
новое семейство требовало нового условия в предикторе. Проверка того среза:
`grep -in "functionalGroup|classif|homolog" core/src/main` давал только `classify` из VSEPR.

## 2. Что стало

`core/chemistry/FunctionalGroups.kt`. Два вывода из графа:

**Функциональные группы** (по атомам): `hydroxyl`, `ether`, `carbonyl`, `carboxyl`, `ester`,
`amine`, `nitrile`, `halide`, `thiol`, `thioether`.

**Классы соединения**: `hydrocarbon`, `alkane`, `cycloalkane`, `alkene`, `diene`, `alkyne`,
`arene`, `alcohol`, `polyol`, `ether`, `aldehyde`, `ketone`, `carboxylic-acid`, `ester`, `amine`
(+ `primary-amine` / `secondary-amine` / `tertiary-amine` по числу водородов на азоте), `nitrile`,
`halide`, `thiol`, `thioether`.

Правила вывода, которые стоит назвать отдельно:

- **Алканы, алкены, диены, алкины** — по числу связей C=C и C≡C. Одна двойная — алкен, две — ещё и
  диен.
- **Арены не считаются алкенами.** Двойные связи Кекуле внутри ароматического кольца исключаются
  из подсчёта: бензол — `hydrocarbon, arene`, а не «диен». Двойная связь вне кольца считается,
  поэтому стирол — `hydrocarbon, alkene, arene`.
- **Цикл против цепи** — по рангу циклов `связи − атомы + компоненты`: циклогексан — циклоалкан,
  декалин имеет ранг 2. Ранг теперь живёт в классификаторе, и `PropertyPredictor.ringCount`
  вызывает его, так что «кольцо» в ядре означает одно и то же.
- **Карбонил уточняется по соседу**: C=O плюс одинарная связь с O, у которого есть водород, —
  карбоксил; плюс O, у которого есть другой углерод, — сложный эфир; иначе карбонил, который
  становится альдегидом при водороде на углероде и кетоном без него.
- **Вода и аммиак не получают органических классов.** У воды кислород без связей, у аммиака азот
  без соседей-углеродов, поэтому `classes("O")` и `classes("N")` пусты. Это не «спирт» и не «амин».

`isHydroxyl` и проверка состава `formula.keys.all { it == "C" || it == "H" }` из предиктора
удалены: ветвь спиртов выбирается как «класс `alcohol` есть, и ни одного класса из
`OXYGEN_CLASSES_BEYOND_HYDROXYL`», ветвь углеводородов — как «класс `hydrocarbon` есть».
Поведение модели кипения при этом не изменилось: этанол, метанол, гликоль, глицерин, гексан,
циклопропан, бензол и толуол дают те же числа, что и до среза (их тесты не правились).

В `PredictedProperties` добавлены `compoundClasses` и `functionalGroups`, `chem lookup` печатает
строки `Compound classes:` и `Functional groups:`.

## 3. Чего классификатор не делает

- **Стереоизомерии нет.** Цис-/транс- и L/D-формы неразличимы: в нотации нет стереодескрипторов, а
  координат нет. Классы у цис- и транс-бутена-2 будут одинаковыми — и это честно, пока нет 3D.
- **Класс не заменяет правило реакции.** Матчеры правил по-прежнему работают по связям; гейты
  «только для алкенов» через классы — следующая работа.
- **Амиды, фенолы, ангидриды, нитросоединения, сульфокислоты** не выделены: фенол сейчас даст
  `alcohol` + `arene`, амид — `amine` + `ketone`. Это грубость, а не ошибка вывода, и она
  исправляется добавлением правил вывода, а не строчками веществ.

## 4. Проверка

- `core/chemistry/FunctionalGroupTest.kt` — 10 тестов: алканы (бутан и изобутан дают один и тот же
  набор классов при разных ID), алкен/диен/алкин, циклоалкан и арен (бензол не диен, стирол —
  алкен и арен), спирты и полиолы, эфир не спирт, альдегид/кетон/кислота/сложный эфир, амины трёх
  степеней, нитрил/галогенид/тиол/тиоэфир, вода и аммиак без классов, ранг циклов 0/1/2.
- Существующие тесты кипения и взаимодействий не изменялись и проходят: выбор ветви через
  классификатор эквивалентен прежним условиям.
- Исполняет CI (локально JDK нет).
