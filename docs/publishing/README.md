# Отложенный комплект публикации ChemMod

**Статус: НЕ ПУБЛИКОВАТЬ.** По решению владельца подготовка публичной страницы
отложена; продолжается разработка. Этот каталог — архив материалов, а не
разрешение создавать новый GitHub Release, тег или страницу CurseForge.
Существующие test-релизы не изменяются.

## Файлы

- `chemmod-curseforge-512.png` — выбранный владельцем логотип, PNG 512×512.
- `chemmod-logo.png` — исходное выбранное изображение, PNG 1536×1536.
- `curseforge-description.md` — английские Summary и Description; описание
  отражает возможности test.7 и требует актуализации перед публикацией.
- `release-preparation.md` — параметры страницы, проверки и границы лицензии.

Логотип получен AI-генерацией, вариант выбран владельцем. Уменьшенная версия
подготовлена из этого же изображения. Это оформление страницы проекта, не
подмена игровых текстур. Все файлы сохранены в репозитории для будущего
использования на GitHub/CurseForge; автоматическая загрузка не настроена.
