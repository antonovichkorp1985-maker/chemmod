# Параметры будущей публикации — черновик

**Публикация отложена владельцем.** Не создавать релиз или страницу автоматически.

## ChemMod

- Название: ChemMod (доступность названия/slug на площадке не проверена).
- Площадка: отдельный проект Minecraft / Mods, рекомендуемая категория Technology.
- Minecraft 1.21.1, NeoForge 21.1.251+, Java 21. Не маркировать как Forge/Fabric.
- Текущий ориентир материалов: `0.9.0-test.7`; для будущего выпуска сверить
  версию, код, инструкции и фактическую готовность. Не выдавать Alpha за Release.
- Сервер и все клиенты: одинаковая версия мода.
- Create и TerraFirmaCraft — необязательные интеграции; Macaw's Furniture и
  Chisels & Bits не являются зависимостями нынешнего JAR.
- Core и Kotlin-runtime включены в модовый JAR; отдельный core-cli не публиковать
  как пользовательский мод. Состав встроенных библиотек и notices перепроверить.
- Исходники: https://github.com/antonovichkorp1985-maker/chemmod
- Ошибки: https://github.com/antonovichkorp1985-maker/chemmod/issues
- Релизы: https://github.com/antonovichkorp1985-maker/chemmod/releases

## Перед будущей публикацией

1. Получить явное решение владельца о публикации.
2. Сверить описание с реально реализованными возможностями, не с планами.
3. Проверить клиентскую графику, выбор предметов, GUI, настоящий restart,
   сохранность содержимого и два клиента. CI не заменяет эти проверки.
4. Сделать реальные игровые скриншоты; логотип не служит доказательством работы.
5. Собрать точный commit, проверить JAR/дескриптор/версию/SHA-256 и зависимости.
6. Для GitHub подготовить новые versioned release notes и checklist; существующие
   теги и опубликованные файлы не переиздавать. Для CurseForge использовать тот
   же проверенный JAR, не всю папку mods и не чужие JAR из сборки.
7. Повторно проверить актуальные требования площадки и наличие project name.

Справочные инструкции площадки (проверять заново перед публикацией):
https://support.curseforge.com/support/solutions/articles/9000197241-creating-and-submitting-a-project
https://support.curseforge.com/support/solutions/articles/9000197321-curseforge-api
